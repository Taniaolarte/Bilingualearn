# BilinguaLearn — Landing Page

Bilingual (English/Spanish) marketing landing page for BilinguaLearn English exam
coaching (PTE · IELTS · CELPIP) in Australia. Static site, no build step.

## Publish on GitHub Pages
1. Publish this repository with GitHub Desktop.
2. On github.com → repo **Settings → Pages** → Source: **Deploy from a branch**,
   Branch: **main**, Folder: **/ (root)** → Save.
3. Live at `https://<your-username>.github.io/<repo-name>/` within a minute.

## Before going public
- Replace `WA_NUMBER = '61000000000'` in `index.html` with the real WhatsApp number.
- Replace the Instagram / Facebook `href="#"` links.
